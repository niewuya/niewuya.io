Work

  • 2025.02 - Present
    Postdoctoral Researcher, Department of Computer Science
    University of Virginia
    Postdoctoral researcher working on AI infrastructure and systems for large-scale LLM and MoE inference on NVIDIA Superchips and heterogeneous CPU–GPU platforms.
    • Designed zero-copy KV-cache offloading on NVIDIA Superchips that treat CPU and GPU memory as a unified heterogeneous hierarchy, with asymmetric CUDA kernels for long-context LLM inference.
    • Developed C2CMoE, an on-demand expert streaming system over NVLink-C2C to eliminate MoE token all-to-all communication by aligning expert placement, streaming, and kernels with the interconnect topology.
    • Ongoing work on serverless LLM serving on MIG-partitioned GPUs, enabling token-level scheduling and fine-grained multi-tenant sharing.
  • 2023.06 - 2025.01
    Postdoctoral Researcher, Department of Computer Science
    Yale University
    Postdoctoral researcher in the Efficient Computing Lab, working on RDMA-based distributed shared memory systems for fine-grained, latency-sensitive workloads.
    • Designed an RDMA-based distributed shared memory (DSM) runtime as a global-memory abstraction for fine-grained, latency-sensitive ML pipelines on RDMA-connected clusters.
    • Explored software-defined cache coherence and data prefetching to balance programming transparency and performance, and systematically compared DSM against RPC-based frameworks.
    • Extended DSM designs toward cross-GPU-node scenarios using GPU-direct RDMA and pinned memory regions as a foundation for cross-node AI memory systems.
  • 2021.04 - 2023.05
    Research Assistant, Cloud and Distributed Systems Lab
    University of Macau
    Research assistant working on workload prediction and resource management for cloud-native microservices.
    • Investigated workload variability in large-scale microservices using deep learning for predictive autoscaling.
    • Proposed resource management frameworks to satisfy SLA requirements and improve resource efficiency in shared clusters.
  • 2018.11 - 2023.01
    Research Intern
    Alibaba Cloud
    Research intern working on large-scale microservice analysis and resource management for production cloud workloads.
    • Analyzed large-scale microservice traces and designed resource management systems for online shopping applications to handle extreme load during the Double 11 festival.
    • Released Alibaba microservices trace datasets (100GB v2021 and 2TB v2022) that are widely used by industry and academic groups.
    • Co-designed Erms, an efficient resource management system for shared microservices with SLA guarantees.
